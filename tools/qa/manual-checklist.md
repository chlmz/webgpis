# GPIS Manual QA Checklist

Use browser widths `1440`, `1024`, `909`, `768`, and `390` px.

- Sticky header remains visible after scrolling beyond 600 px.
- Scrolling causes no layout jump and no horizontal overflow.
- Home navigation anchors land visibly below the sticky header.
- Mobile menu opens and closes repeatedly.
- Clicking a mobile navigation link closes the menu.
- `aria-expanded` updates correctly on the mobile toggler.
- Browser console shows no errors.
- Home, Coorte, Pessoas, and publications remain visually unchanged.
